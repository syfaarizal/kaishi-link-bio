# kaishi-link-bio

Personal **link-in-bio** website built with modern front-end stack.
Fast, minimal, and focused on showcasing identity, links, and interaction.

## ✨ Features

* Clean link-in-bio layout
* Custom animations & UI polish
* Built-in AI chat modal
* Responsive and mobile-first
* Ready for production deployment

## 🛠 Tech Stack

* **Vite**
* **React**
* **Tailwind CSS v4**
* **Lucide Icons**

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 🌐 Deployment

Optimized for **Vercel** deployment.

Environment variables required:

```
VITE_OPENROUTER_API_KEY=your_api_key_here
VITE_OPENROUTER_MODEL=openai/gpt-4.1-mini
```

## 📁 Notes

* `.env` is excluded from version control
* Tailwind CSS uses the v4 Vite plugin setup
